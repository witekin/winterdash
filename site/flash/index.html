WinterDashInstaller

This installer needs a computer with Chrome or Edge.
Web-based flashing uses a browser feature (Web Serial) that phones, tablets, Safari and Firefox don't have. Open this page on a Windows / Mac / Linux computer in Chrome or Edge — or flash manually (see the wiki).

SELECT BOARD
—%
Plug your board into a USB port, then press Connect.
Didn't see your board in the list, or it won't connect? You probably need the USB driver:
  • CP210x driver — Silicon Labs (most TTGO / CP2102 boards)
  • CH340 / CH341 driver — many generic ESP32 dev boards
Install it, unplug and replug the board, then Connect again. Make sure the USB cable is a data cable, not charge-only.

WinterDash is open-source firmware that reads a Victron Blue Smart charger over
        Bluetooth and shows it on a little screen, a web page, and Home Assistant. This page flashes it onto an ESP32
        board — about a minute, nothing to install on your computer. When it finishes, the board makes its own
        WinterDashAP Wi-Fi network you finish setup from on your phone.
